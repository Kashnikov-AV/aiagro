# AIagro
## Описание

AIagro - это приложение для обнаружения растений на изображениях с камеры в реальном времени. Использует алгоритмы компьютерного зрения для сегментации растительности и подсчёта количества растений.

## Возможности

- 🎥 **Работа с камерой** - захват видео в реальном времени
- 🌱 **Обнаружение растений** - использование цветовых индексов (ExG, ExR, ExGR, CIVE)
- 📊 **Анализ размеров** - классификация растений по размеру (малые, средние, большие)
- 🔧 **Управление клапанами** - контроль полива через GPIO (Orange Pi)
- 🖥️ **Современный интерфейс** - PyQt6 с темой Fusion

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd aiagro
```

2. Установите зависимости:
```bash
pip install PyQt6 opencv-python numpy
```

Для работы с GPIO на Orange Pi дополнительно установите:
```bash
pip install OPi.GPIO
```

## Технические детали

### Алгоритм обнаружения растений

Приложение использует следующие цветовые индексы для сегментации растительности:

- **ExG** (Excess Green) - избыток зелёного
- **ExR** (Excess Red) - избыток красного
- **ExGR** (Excess Green minus Excess Red)
- **CIVE** (Colour Index of Vegetation Extraction)

После вычисления индекса применяется пороговая обработка Otsu для бинаризации изображения и морфологические операции для улучшения результата.

### Классификация размеров

Растения классифицируются по площади:
- **Малые**: площадь < 0.0001 от общего размера изображения
- **Средние**: масштаб 9x9
- **Большие**: масштаб 4x4

### Управление клапанами

Модуль `ValveController` поддерживает:
- Автоматическое закрытие клапана после заданного времени
- Потокобезопасную работу с блокировками
- Режим отладки без реального GPIO

## Аппаратные требования

- Камера USB (веб-камера)
- Orange Pi или совместимая плата с GPIO (опционально, для управления клапанами)
- Электромагнитный клапан полива (опционально)
